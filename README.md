# AI Support Ticket Analytics Pipeline

## Overview
This project builds an end-to-end data pipeline that processes customer support tickets, applies AI-based classification, and generates business insights through dashboards.

## Architecture
Dataset → ETL Pipeline → PostgreSQL → ML Model → Prediction Pipeline → Power BI Dashboard

## Tech Stack
- Python
- PostgreSQL
- Scikit-learn
- Power BI

## Features
- Data cleaning and transformation
- NLP-based ticket classification (TF-IDF)
- Automated prediction pipeline
- Dashboard with operational KPIs

## Use Case
Simulates a real-world support system where tickets are automatically categorized and analyzed.
